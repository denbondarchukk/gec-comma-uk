# GEC Comma UK 🇺🇦

**GEC Comma UK** — це інтелектуальна навчальна система для автоматичного виправлення пунктуаційних помилок, пов’язаних із вживанням коми в українськомовних текстах. 

Проєкт поєднує в собі сучасні нейромережеві технології (модель токен-класифікації на базі архітектури Transformers) та *rule-based* алгоритм для лінгводидактичної підтримки користувачів. Відповідно, система не лише виправляє помилки, а й розпізнає синтаксичний контекст, пояснює правила та пропонує інтерактивні вправи для закріплення матеріалу.

---

## 🚀 Основні можливості

* **Автоматична корекція:** виявлення пропущених або зайвих ком за допомогою донавченої моделі-трансформера.
* **Аналіз контексту:** алгоритмічна ідентифікація конкретних лінгвістичних конструкцій.
* **Інтерактивне навчання:** динамічне завантаження теоретичних довідок та практичних вправ (тестів) із хмарної бази даних Supabase.
* **Стійкість до некоректного введення:** автоматичне виявлення надмірної або спамової пунктуації та очищення тексту).
* **Сучасний веб-інтерфейс:** інтуїтивно зрозуміле графічне середовище користувача, розроблене на базі фреймворку Gradio.

---

## 📁 Структура проєкту

Архітектура репозиторію має чіткий поділ на компоненти машинного навчання, серверної логіки, конфігурацій та дидактичних матеріалів:

* `datasets/` — директорія з вихідними анотованими текстовими масивами.
* `ann_to_dataset.py` — скрипт для конвертації вихідних анотацій у лінгвістичний формат датасету.
* `punctuation_error_counter.py` — скрипт для статистичного підрахунку та аналізу пунктуаційних помилок із комою.
* `comma_error_detector_training_ipynb.ipynb` — інтерактивний блокнот Jupyter Notebook із повним процесом донавчання ML-моделі.
* `app.py` — головний файл запуску, побудови дизайну та конфігурації веб-інтерфейсу Gradio.
* `logic.py` — модуль бізнес-логіки для обробки вхідного тексту, rule-based аналізу та координації сценаріїв навчання.
* `utils.py` — допоміжні лінгвістичні утиліти (визначення дієприслівників, порівняння текстів, фільтрація спаму знаками).
* `database.py` — модуль інтеграції, отримання правил та виконання запитів до хмарної СКБД Supabase.
* `config.py` — файл ініціалізації pipeline моделі, системних констант та зчитування змінних оточення.
* `schema.sql` — SQL-скрипт для генерації структури реляційних таблиць та первинного заповнення бази даних.
* `exercises_data.docx` — систематизований електронний масив практичних вправ, який став основою для наповнення СКБД.
* `requirements.txt` — список усіх залежностей та бібліотек проєкту.

## 🧠 Модель

В основі системи лежить модель **XLM-RoBERTa-base-uk**, донавчена на спеціалізованому корпусі на основі даних UA-GEC від Grammarly. Завдяки оптимізації архітектури, переходу на бінарну токен-класифікацію та розширенню навчального корпусу до **40 000 міток** (токенів), модель демонструє високу точність обробки синтаксичних конструкцій із показником $F_1$-міри **майже 90%**.
